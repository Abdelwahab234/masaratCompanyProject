# masaratCompanyProject
تصميم وتطوير موقع إلكتروني تعريفي (Corporate Website) حديث وثنائي اللغة (عربي / إنجليزي) لشركة "مسارات التنمية الحديثة للمقاولات"، وهي شركة رائدة في المملكة العربية السعودية متخصصة في الحلول الهندسية المتكاملة وتمديد شبكات الغاز المسال (LPG) وأنظمة الحماية وكشف التسرب.

تم بناء الموقع ليعكس احترافية الشركة ومكانتها في السوق، ويستعرض خدماتها المتنوعة بأسلوب تفاعلي وجذاب. يتضمن الموقع عدة أقسام رئيسية:

الرئيسية (Hero Section): واجهة جذابة تلخص هوية الشركة.

من نحن (About Us): استعراض لرؤية الشركة، أهدافها، وقيمها.

الخدمات (Services): عرض تفصيلي لخدمات التصميم، التشغيل، الصيانة، والاستشارات الهندسية.

معرض المشاريع (Portfolio): قسم متقدم لعرض سابقة أعمال الشركة مقسمة حسب القطاعات (حكومية، مصانع، فنادق، مطاعم، إلخ) مع إمكانية البحث والفلترة.

أنظمة الغاز (Gas Systems): عرض متخصص لمكونات الغاز وحلول الصيانة.

شركاء النجاح والموردون: إبراز شبكة عملاء الشركة والجهات الموردة المعتمدة.

تواصل معنا: نموذج اتصال سريع لتسهيل طلب الاستشارات وعروض الأسعار.

🎯 الجمهور المستهدف (Target Audience):

القطاع التجاري والصناعي (B2B): المستثمرون، المصانع، المولات التجارية، والفنادق التي تبحث عن مقاول معتمد لتركيب شبكات الغاز وأنظمة الإطفاء.

القطاع الحكومي وشبه الحكومي: الجهات التي تتطلب معايير جودة وسلامة عالية في تنفيذ المشاريع.

أصحاب المشاريع السكنية والمنتجعات: الباحثين عن حلول آمنة ومتطورة للغاز المركزي.

المقاولون وشركات إدارة المرافق: للبحث عن شراكات أو التعاقد من الباطن لأعمال الصيانة والتشغيل.

💻 التقنيات والأدوات المستخدمة (Technologies Used):

تم بناء المشروع باستخدام أحدث تقنيات تطوير الويب لضمان أداء عالٍ، وسرعة في التصفح، وتجربة مستخدم (UX) ممتازة:

إطار العمل الأساسي: Next.js 14 (React 18) لضمان أفضل أداء وتهيئة ممتازة لمحركات البحث (SEO).

لغة البرمجة: TypeScript لكتابة كود قوي، آمن، وخالٍ من الأخطاء.

التصميم وتنسيق الواجهات: CSS Modules لتنسيق احترافي ونظيف يضمن عدم تداخل الأنماط (Styles).

الحركات والتفاعلية (Animations):

Framer Motion لإنشاء حركات تفاعلية سلسة ومتقدمة للعناصر.

AOS (Animate On Scroll) لظهور العناصر بشكل جذاب أثناء التمرير.

الأيقونات: Lucide React لاستخدام أيقونات حديثة وعالية الدقة تعزز من جمالية التصميم.

دعم اللغات: نظام هيكلي مخصص يدعم اللغتين العربية والإنجليزية (RTL / LTR) بسلاسة كاملة.
